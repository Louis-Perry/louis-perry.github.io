# Assets Directory

Drop your personal photos and downloadable documents into this folder using the exact filenames below:

| File | Status | Purpose |
| :--- | :--- | :--- |
| `hero-bg.jpg` | **Add your photo** | Full-bleed background portrait for the **Home** hero (`hero-bg-fallback.svg` renders automatically until you add this photo). Landscape outdoor/mountain or portrait-in-context photos work best. |
| `headshot.jpg` | **Add your photo** | Circular portrait shown on the **About Me** page (`headshot-placeholder.svg` displays automatically until you add this file). |
| `Louis_Perry_CV.pdf` | **Add your updated CV** | Linked to the **Download CV** buttons and the coastal Noticeboard landmark on the isometric map. |
| `dissertation-scheme.png` | **Included (Scheme 1)** | High-resolution crop of Scheme 1 from your BSc dissertation (swap anytime). |
| `Louis_Perry_Dissertation.pdf` | *Optional* | Drop your thesis or poster PDF here and set `featuredResearch.documentUrl` in `js/site-data.js`. |
